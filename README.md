# Business HQ — sample website

The original plain HTML/CSS/JavaScript Business HQ booking prototype.

## Hosting

GitHub Pages source: **main / repository root**.

Site address after publication: https://rikbanerjee.github.io/smbOS/

No build command, npm install, Vercel account, Firebase, or database is required. Keep `index.html`, `styles.css`, `app.js`, and `model.js` together. `.nojekyll` disables Jekyll processing.

## Try the demo

Choose **Build my fall visit**, configure the fictional property and services, select a Thursday that fits the complete visit, review the price, and confirm. Open **Joe’s workspace** for the day's jobs and preparation checklist. Use **My bookings** to reschedule, cancel, or rebook.

## Demo limits

- Fixed sample dates in October/November 2026, fictional business/contact details, and illustrative travel/pricing rules.
- Bookings stay in each visitor's browser; visitors do not share a real calendar or customer database.
- No payments, messages, or real jobs are created. Tax is illustrative at $0.
- Portable demo links are readable, unsigned snapshots. They do not synchronize later changes and are not secure production recovery links. Use fictional information only.
- Production authentication, verified addresses, server-authoritative pricing, transactional scheduling, payment collection, and recovery require a backend.
- The interface optionally loads Google Fonts, with system fonts as fallback.

This static sample is separate from the React contribution in `nullwavelabs/business-hq-web`.
